**Task Management System for Technical Summative 1**

** Project Description**
The Tasks for Today Management System is a CodeIgniter 4 web application designed to help users organize and monitor their daily tasks. The system displays tasks scheduled for the current date, provides a complete list of all tasks, and allows users to update task statuses between `pending` and `completed`. This project was created as a laboratory activity to demonstrate the use of CodeIgniter 4, PHP, MySQL, models, controllers, routes, views, and database operations.
