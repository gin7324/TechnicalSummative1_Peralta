**Task Management System for Technical Summative 1**

**Project Description**

The Tasks for Today Management System is a CodeIgniter 4 web application designed to help users organize and monitor their daily tasks. The system displays tasks scheduled for the current date, provides a complete list of all tasks, and allows users to update task statuses between `pending` and `completed`.

 
**Features**

- Displays only today's tasks on the Welcome page.
- Displays all tasks on the Task List page.
- Sorts tasks by task date.
- Allows users to mark tasks as completed.
- Saves task status changes to the database.
- Provides search and status filtering for tasks.
- Displays a demo user's information on the Profile page.
- Includes an About page identifying the developer.
- Uses a responsive black-and-white interface.
- Supports desktop and mobile screen sizes.
